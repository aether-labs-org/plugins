# Stack profile - JVM (Java and Kotlin)

Gradle is the example (the wrapper `./gradlew`); the Maven equivalents are in the Alternatives column. Gradle skips up-to-date tasks, so clean the task first (`cleanTest test`): a report older than the run is an error. The versions in the Fixture column are the ones the output was recorded with.

One row per topic id of the area files. The **Command** column emits a format kh parses (or only an exit code). **Fixture** is the recorded real output of that tool under `cli/kh/testdata/formats/` (a path without extension; it verifies the output format, not necessarily the exact command of the row), `n/a (exit code)` for a keel builtin or a `kh` command whose exit code is the verdict and that ran in the tests, `unverified (exit code, not run)` for an external tool that is judged by its exit code and whose command was never run while this catalog was written (taken from its documentation: run it once and read the exit code before trusting it), or `unverified` when a parsed format has no recorded output. Say so when proposing an unverified row. The user chooses: any tool that emits a supported format, or only an exit code, is accepted.
