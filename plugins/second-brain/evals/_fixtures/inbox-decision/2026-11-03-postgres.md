# Banco de dados padrão

Decidimos adotar PostgreSQL como banco padrão a partir de dezembro, porque o time já o conhece,
ele cobre nossos casos de JSON e busca textual sem outro serviço, e a licença não nos prende a
um fornecedor. Consideramos MySQL e MongoDB; o MySQL perdeu em recursos de JSON e o MongoDB
exigiria treinar o time do zero. Consequência: projetos novos usam PostgreSQL por padrão, e os
serviços atuais migram só quando forem mexidos de qualquer forma.
