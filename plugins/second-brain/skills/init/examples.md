# Example folder structures

Adapt names, descriptions and conventions to the user's answers and language. Folders are
top-level under `wiki/`; one sub-level is allowed (`Areas/Health`).

## Personal knowledge (PARA)

- `Projects`: active efforts with a goal and an end date. One note per project.
- `Areas`: ongoing responsibilities (health, finances). One subfolder per area.
- `Resources`: concepts and references reused across projects. Atomic notes.
- `Archive`: inactive notes; move here instead of deleting.

## Individual work

- `Projects`: work in progress, one note per project with status and next step.
- `Decisions`: one note per decision: context, options, choice, consequences.
- `Meetings`: one note per meeting: date, people, outcomes; link the decisions it produced.
- `Resources`: tools, concepts and references.
- `Archive`: finished work.

## Project or team

- `Context`: goals, scope, stakeholders and constraints.
- `Decisions`: one note per decision, linked to the context it came from.
- `Meetings`: minutes with decisions and owners.
- `References`: external documents, standards and sources.
- `Glossary`: one note per term, in the team's words.
- `Archive`: superseded material.
