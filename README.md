# aether-labs plugins

A collection of Claude Code plugins by Aether Labs.

## Plugins

| Plugin | Description | Install |
|--------|-------------|---------|
| keel-harness | Assess, install and maintain an AI-agent harness in a repository. | `/plugin install keel-harness@aether-labs` |

## Installation

First, add the marketplace:

```
/plugin marketplace add aether-labs-org/plugins
```

Then, install the desired plugin:

```
/plugin install keel-harness@aether-labs
```
