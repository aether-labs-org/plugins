# keel v0.4 — M0 Core run: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go binary, `kh`, whose `kh run -- <command…>` runs any command from the repository root with
a process group and a timeout, captures stdout and stderr in order, redacts secrets, stores the evidence
under an execution ID with retention, and prints a short deterministic verdict; `kh show <id>` reads the
evidence back.

**Architecture:** A new Go module in `cli/kh/` (built from scratch; nothing from the `feat/keel-cli`
branch is required). `internal/run` executes; `internal/redact` filters the byte stream on its way to
`output.log`; `internal/evidence` owns IDs, the run directory, `meta.json` and pruning; `internal/tree`
fingerprints the work tree; `internal/reduce` and `internal/render` turn a log into the agent-facing
text; `internal/cli` wires the commands. `meta.json` **is** the `--json` result: one schema.

**Tech Stack:** Go 1.27.3, standard library only; bash 3.2 for the end-to-end test; git.

**Spec:** `docs/specs/2026-11-03-keel-cli-v0.4-design.md` — read §5, §6, §7, §8 (isolation), §9.2 and
§14 (M0 row) before Task 1. This plan implements milestone M0 only. It also implements the **generic
reduction** of §6.3 item 2, which §14 lists under M2, because `kh run --` has nothing else to print; M2
keeps the format parsers.

## Global Constraints

- Module `github.com/aether-labs-org/plugins/cli/kh` in `cli/kh/`; `go.mod` has `go 1.27` and `toolchain go1.27.3`.
- Standard library only in M0 (no YAML yet: `.agents/keel.yml` is located, not parsed).
- Builds use `CGO_ENABLED=0 -trimpath -buildvcs=false`; `main.version` is set with `-ldflags "-X main.version=…"`, default `0.4.0-dev`.
- Platforms: Linux and macOS (`//go:build unix` where `syscall` process-group calls are used). No Windows code.
- No network and no model call anywhere in `kh`.
- Nothing under `plugins/` changes in M0: `git diff --stat <base> -- plugins/` stays empty.
- Code, comments, docs and commit messages in English.
- Evidence lives in `.agents/run/runs/<id>/`; at most **50** runs and **200 MB**; never commit it.
- Redaction placeholder is exactly `‹redacted›` (U+2039, U+203A).
- Exit codes of `kh run`: `pass` 0, `fail` 1, `skip` 2, `error` 3; bad usage 64; no `.agents/keel.yml` found 3.
- Default timeout **10m**; kill grace **5s** (SIGTERM to the group, then SIGKILL).
- `make check` (`./tests/run.sh`) and `make validate` stay green after every task.
- `go` on the owner's machine is a snap: capture its output with `… 2>&1 | cat`, never `> file` under `/tmp/claude-1000`.

## Review Focus

1. **A single huge line with no newline** (minified JSON, a 2 MB stack dump) — the log keeps it, nothing blows up, and the text output shows it cut at 300 characters with `…`. Pinned: Task 2 `TestRedactHugeLine`, Task 6 `TestRenderCutsLongLines`.
2. **Binary or non-UTF-8 output** (`head -c 4096 /dev/urandom`) — the log keeps the bytes; the text output contains only valid UTF-8 and no control characters other than tab. Pinned: Task 6 `TestRenderSanitizesBytes`.
3. **`kh` started from a subdirectory** — the root is found upward and the command runs in the root. Pinned: Task 1 `TestFindRootFromSubdir`, Task 7 e2e "runs from the root".
4. **Ctrl-C on `kh` while the command runs** — the whole process group dies, `meta.json` is still written with `status: error`, summary `interrupted`, and `kh` exits 3. Pinned: Task 3 `TestRunCancelKillsGroup`, Task 7 e2e "SIGINT".
5. **A secret in the command line itself** (`kh run -- curl -H "Authorization: Bearer ghp_…"`) — the `command` field of `meta.json`, the text header and `output.log` never contain it. Pinned: Task 7 e2e "secret in argv".

### Task 2: Redaction

**Files:**
- Create: `cli/kh/internal/redact/redact.go`, `cli/kh/internal/redact/redact_test.go`

**Interfaces:**
- Produces: `redact.New(env []string) *Redactor`
- Produces: `(*Redactor) String(s string) string`
- Produces: `(*Redactor) Writer(dst io.Writer) io.WriteCloser` — line-buffered; `Close` flushes a final line with no newline; it does not close `dst`.
- Produces: `redact.Placeholder = "‹redacted›"`

Rules (spec §7):
- **Env values**: a variable whose name matches, case-insensitively, `TOKEN`, `SECRET`, `PASSWORD` or `CREDENTIAL` anywhere, or ends with `_KEY`, has its value redacted when the value is at least 6 bytes long. Longer values are replaced first.
- **Patterns**: `\b(AKIA|ASIA)[0-9A-Z]{16}\b`; `\bgh[pousr]_[A-Za-z0-9]{36,}\b`; `\bgithub_pat_[A-Za-z0-9_]{22,}\b`; `\beyJ[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}\b`.
- **Private key blocks**: every line from a `-----BEGIN [A-Z ]*PRIVATE KEY-----` line through the matching `-----END … PRIVATE KEY-----` line becomes a single `‹redacted›` line. An unterminated block is redacted up to EOF.

### Task 3: Runner — process group, timeout, cancel, ordered capture

**Files:**
- Create: `cli/kh/internal/run/run.go`, `cli/kh/internal/run/run_test.go` (both `//go:build unix`)

**Interfaces:**
- Produces:

```go
type Spec struct {
    Argv      []string      // executed directly, no shell (M1 passes ["bash","-o","pipefail","-c",run])
    Dir       string
    Env       []string
    Timeout   time.Duration // 0 → DefaultTimeout
    KillGrace time.Duration // 0 → DefaultKillGrace
}
type Outcome struct {
    ExitCode    int  // the process's code; a signal-terminated process reports 128+signal (SIGKILL → 137)
    TimedOut    bool
    Interrupted bool // ctx was cancelled (Ctrl-C on kh)
    NotFound    bool // Argv[0] could not be found or executed (exec.ErrNotFound, ENOENT, EACCES)
    StartErr    error
    Started, Finished time.Time
}
const DefaultTimeout = 10 * time.Minute
const DefaultKillGrace = 5 * time.Second
func Run(ctx context.Context, s Spec, out io.Writer) Outcome
```

Approach: one `os.Pipe()` given to both `cmd.Stdout` and `cmd.Stderr`, so the child's writes reach the pipe in their real order; the parent closes the write end after `Start` and copies the read end into `out`. `SysProcAttr{Setpgid: true}`. On timeout or ctx cancel: `kill(-pgid, SIGTERM)`, wait up to `KillGrace`, then `kill(-pgid, SIGKILL)`. After the main process exits, also send `kill(-pgid, SIGKILL)` (ignore `ESRCH`) so background children never hold the pipe open (spec §8: the group is killed on exit).

**Interfaces:**
- Produces (`reduce`):

type Line struct { N int; Text string }       // 1-based line number in output.log
type Reduction struct { Matches, Tail []Line; Total int }
var Vocabulary = regexp.MustCompile(`(?i)\b(error|errors|fail|failed|failure|exception|panic|traceback|fatal)\b`)
const MaxMatches = 5
const TailLines = 10
func FromFile(path string) (Reduction, error) // Matches: the first 5 lines matching Vocabulary; Tail: the last 10 lines not already in Matches

- Produces (`render`):

```go
const MaxLineRunes = 300
func Duration(ms int64) string // < 1000 → "NNNms"; else "S.Ds" (one decimal, truncated), as gate.sh

func Failures(res result.Result, ctx []reduce.Line) string
```

`render.Run` output (exact; two spaces between header fields; `exit=-` when `ExitCode` is null):

```
<name>  <STATUS>  exit=<code>  <duration>  <summary>  [run <id>]
  <match lines, each "  <text>">                       ← only when status != pass
  --- last <k> lines ---                                ← only when status != pass and Tail is non-empty
  <tail lines, each "  <text>">
evidence: kh show <id> [--failures | --full]
```

`<name>` is `res.Script`, else the base name of the first word of `res.Command`. `<STATUS>` is upper case. Every printed log line is cut to `MaxLineRunes` runes plus `…`, has invalid UTF-8 replaced with U+FFFD, and has control characters other than tab removed.

`render.Failures`: the header line, then each context line as `<N>: <text>` with `--` between non-adjacent groups.

`kh run` sequence:
1. `root.Find(cwd)` (else exit 3: `kh: no .agents/keel.yml here or in any parent directory`).
2. `redact.New(os.Environ())`.
3. `tree.Fingerprint(root)`, taken **before** the run: the state the command saw.
4. `evidence.Create`.
5. `run.Run` with `Dir: root` and `ctx` from `signal.NotifyContext(SIGINT, SIGTERM)`, writing through the redactor into `output.log`.
6. `result.Classify`; fill `Result`. `Command` is `redactor.String(strings.Join(argv, " "))`, and `Evidence.Dir`/`Log` are relative to the root.
7. `WriteMeta`.
8. `Prune(root, id, MaxRuns, MaxBytes)` (a prune error is printed to stderr and never changes the verdict).
9. Print `render.Run`, or the meta JSON with `--json`; exit `Status.ExitCode()`.

`--timeout` takes a Go duration, and an invalid value exits 64. A missing `--` or command exits 64.

`kh show`:
- **default:** `render.Run` recomputed from `output.log`;
- `--failures`: `render.Failures` with `reduce.Context(…, radius 2)` over Matches;
- `--full`: `output.log` verbatim (already redacted);
- `--json`: `meta.json`.

An unknown or malformed ID exits 64 with `kh: no run <id>`.
